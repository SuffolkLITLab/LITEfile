# Can I file here?

Use this page to check if LITEfile can send your papers.

## Is your state on the list?

LITEfile works with courts in **Illinois**, **Massachusetts** and **Vermont**.
When you open LITEfile, you choose your state first.

<img src="/img/user-guide/choose-state.png" alt="Choose your state page with buttons for Illinois, Massachusetts and Vermont." className="doc-screenshot" width="600" loading="lazy" />

Not every court or case type in a state may be available. If LITEfile does not
show your court or the kind of case you need, you can't file it here yet.

## New case or existing case?

You need to know which one you have.

| If... | Then you have... |
| --- | --- |
| You are starting something, like suing someone or asking for a divorce. There is **no case number** yet. | A **new case** |
| Someone already took you to court, or you filed before. Your papers have a **case number**. | An **existing case** |

The case number is usually near the top of the first page of court papers.

## When to file another way

LITEfile may not be the right tool if:

- **It's an emergency.** For example, you need protection from abuse today.
  Call or go to the court. Many courts take emergency papers in person.
- **Your court or case type isn't listed.** Use the court's own e-filing system,
  or file in person or by mail.
- **You can't use a computer or the internet.** Some courts let people file on
  paper. Ask the clerk.

Illinois has rules about who must file online and who can file on paper. Read
[the Illinois e-filing page](https://www.illinoiscourts.gov/self-help/how-to-e-file)
or ask the clerk.

## What you need to start

- Your finished, signed forms. See [Get your forms ready first](./before-you-begin.md).
- An email address you can check.
- A way to pay the court fee, or a fee waiver form.
- Your case number, if you have an existing case.
