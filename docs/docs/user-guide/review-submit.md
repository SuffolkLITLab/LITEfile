# Step 10: Review and submit

**What you will do:** Check your whole filing, then send it to the court.

**Before you start:** Finish the steps before this one. In an existing case,
make sure your proof of service is filled out. See
[Send copies to the other side](./serve-papers.md).

## Steps

1. Read each section: **Case**, **Documents**, **Your information**, **Other
   people** and **Payment**.
2. Open **View PDF** for each document. Check every page one last time.
3. To change something, choose **Edit** next to that section. When you finish,
   LITEfile brings you back here.
4. Read **Before you submit your filing**. These are the court's rules.
5. Check the box that says you read and accept them.
6. Choose **Submit and pay** (or **Submit filing** if there is no charge).
7. Wait. Don't close the page or press the button again.

## What you should see

A page that says **Your filing was sent to the court**, with a
**Confirmation number**. Write it down or take a screenshot.

<img src="/img/user-guide/confirmation.png" alt="Your filing was sent to the court. Confirmation number 325803, court DuPage County, 1 document sent, and a View filing status button." className="doc-screenshot" width="700" loading="lazy" />

**Sent does not mean accepted.** A clerk still needs to review your papers.

## If something is different

- **"Before you can submit" list:** Fix each item it lists. Then try again.
- **The fee changed:** You changed something that affects the fee. Check it
  and continue.
- **The court's rules changed:** Read the new text and check the box again.
- **An error appears, or the page stops loading:** Don't submit again right
  away. Go to **My filings** to see if it went through. If you're not sure,
  contact the clerk or [LITEfile support](./get-help.md#litefile-help) first.
  Sending twice could mean paying twice.
