About this exploration

Concept A proposes a small, bounded check of filenames and opening-page text to suggest a source. Concept B requires the filer to choose a source. Both use only the confirmed document and page range for subsequent case suggestions. All document previews, model choices, and results here are hand-authored examples.

The full files stay in the filing. Choosing a source does not decide the court’s filing code or lead-document category. No real files, model requests, accounts, or filing services are connected.
